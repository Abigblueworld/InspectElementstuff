# InspectElementstuff
Antinspect, Filterity, and Proinspecial programs I made for HTML sites using JS.<br><br>
<b>These are plugins that you put into your website or game's main JS code to do things with inspect element editors. They are quick, and can be very hard to stop<b>
## Antinspect 
- Is good for anti-cheating on web-based games.
- Can be good if you want no one to edit your site even privatly.
- Is good for avoiding any false rumors.
## Fitlerity
- Use to block out words and reverse any bad inspect element edits.
- Best used to avoid offensive publications.
## Proinspecial
- Is good for adding a twist to your websites
- Games without text-inputs can now use such with this.
- Can be combined with Fitlerity to make it safe.
